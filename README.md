# pr-workflow-demo

Sandbox repository demonstrating the full issue → branch → pull request → review → merge workflow for a Git &amp; GitHub workshop.

## About this repository

This repository is a sandbox for a hands-on **Git &amp; GitHub workshop**. Students can explore it to see a realistic change done properly: a short issue describing the work, a feature branch, focused commits, a pull request, status checks, and a merge into the default branch.
